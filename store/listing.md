## Short description (132 char limit)

```
Adaptive feed scrolling with local hiring detection, a private saved/applied pipeline, and exports that never leave your device.
```

## Detailed description

```
Linkerter makes a LinkedIn feed readable again. It scrolls at a pace you set, spots the
posts that are actually hiring, and keeps a private pipeline of what you saved and where
you applied — all on your own machine.

SCROLL LESS
• Adaptive pacing: Standard, Fast, or Super Fast, with automatic pauses when you start
  reading instead of a fixed timer.
• Hard limits: a time cap and a step cap per session, so one run cannot run away.
• Works in the background: scrolling continues while you use another tab, and Chrome is
  told to keep it alive.
• Stop always works: the Stop button, the popup closing, or the feed tab going away.

FIND THE HIRING POSTS
• A local classifier reads each post and separates openings from recruiter searches,
  job-seeker posts, hiring commentary, and closed roles.
• Evidence, not vibes: every result shows why it matched — opening phrase, application
  call to action, contact address, job-board link, hashtag, role marker.
• Tune it: filter by category, search inside results, sort by relevance or date, and
  choose how much of each post is expanded.

YOUR OWN PIPELINE
• Mark a post Saved or Applied with one click, straight from the result row.
• A "New" chip counts everything first seen since your last run, so you can start each
  session with a triage queue instead of a wall of posts.
• Your own review labels stay local, alongside the saved/applied state.

PRIVATE BY DESIGN
• No account, no AI service, no uploads, no telemetry. The extension has no server.
• History is off by default. When you turn it on it is session-scoped or stored locally,
  with a retention window you choose.
• Exports to JSON, CSV, HTML and Markdown are written by your browser to your disk.
• Full post text and e-mail addresses are excluded from exports unless you opt in.

INTERFACE
• English interface with a light theme.
• Keyboard shortcuts: Ctrl+Shift+L opens the popup, Ctrl+Shift+M starts or stops the
  hiring monitor, Ctrl+Shift+S starts or pauses feed scrolling. All three are remappable
  at chrome://extensions/shortcuts.

WORKS WITH
Chrome 110 and newer on desktop, on linkedin.com/feed. Nothing runs anywhere else.

Linkerter is an independent tool. It is not affiliated with, endorsed by, or sponsored by
LinkedIn.
```

## Permission justifications

| Permission | Justification to paste into the dashboard |
| --- | --- |
| `activeTab` | Used when you click a button in the popup, to act on the LinkedIn tab you already have open. |
| `scripting` | Injects the scroll controller and the hiring monitor into the LinkedIn feed tab you selected. No other site is touched. |
| `storage` | Stores your preferences, the saved/applied pipeline, review labels and, only if you enable it, a local post history. All of it stays in `chrome.storage.local` on your device. |
| Host permission `https://www.linkedin.com/*` | Required to read feed posts, expand "see more", and scroll the feed. The content script runs only on linkedin.com feed URLs. |
| Remote code | None. The extension ships no remote code, no eval, and no network requests. |

## Regenerating

```
npm run store:assets            # all frames
npm run store:assets -- --only screenshot-1
```

Capture uses the Playwright CLI already installed on the machine and falls back to the
installed Chrome when Playwright's bundled browser is missing. Nothing is added to
`package.json`, and `store/` plus `scripts/` are excluded from the packaged archive by
`tests/packager.test.js`.
