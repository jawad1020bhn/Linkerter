# Browser screenshot evidence

No real-browser screenshots were produced in the original authoring sandbox because Chrome was unavailable. Do not treat this directory as evidence of a completed browser gate.

When `npm run test:browser` runs successfully, it captures `popup-en.png` and `popup-ar.png` from the actual extension popup using synthetic intercepted feed data. Review every capture before using it in a store listing. Authenticated-site screenshots require separate owner approval and must be sanitized without misrepresenting the source.
